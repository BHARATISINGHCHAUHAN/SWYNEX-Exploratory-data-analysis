# \# Task 2 – Customer Churn Modeling Analysis | Excel

# 

# \## 📌 Project Overview

# 

# This project was completed as \*\*Task 2 of my Data Analytics Internship at \[SWYNEX Technologies](https://www.linkedin.com/company/swynex/)\*\*.

# 

# The objective of this project was to perform Exploratory Data Analysis (EDA) on customer churn data using Microsoft Excel and identify meaningful patterns in customer churn behavior.

# 

# The project involved data cleaning, statistical analysis, data categorization, Pivot Tables, Pivot Charts, and business insight generation to understand churn rates across different customer attributes.

# 

# \## 🎯 Project Objectives

# 

# \- Perform Exploratory Data Analysis (EDA) on customer churn data.

# \- Clean and prepare the dataset for analysis.

# \- Calculate statistical measures such as Mean, Median, and Mode.

# \- Create categories for meaningful comparisons.

# \- Analyze churn rates using Pivot Tables.

# \- Visualize churn patterns using Pivot Charts.

# \- Identify key insights to understand customer churn behavior.

#

# \- Data Categorization

# \- Pivot Tables and Pivot Charts

# \- Churn Rate Analysis

# \- Data Visualization

# \- Business Insight Generation

# 

# \## 📊 Analysis Performed

# 

# The analysis focused on understanding customer churn patterns across multiple attributes:

# 

# \- \*\*Geography-wise Analysis:\*\* Compared customer churn rates across geographical regions.

# \- \*\*Credit Score Analysis:\*\* Examined churn patterns across different credit score categories.

# \- \*\*Salary-wise Analysis:\*\* Analyzed churn rates among customers with different salary levels.

# \- \*\*Balance-wise Analysis:\*\* Compared churn rates across customer balance categories.

# \- \*\*Tenure-wise Analysis:\*\* Explored the relationship between customer tenure and churn behavior.

# 

# \## 🔍 Key Insights

# 

# 💰 \*\*High-Balance Customers:\*\* Recorded the highest churn rate of \*\*23.41%\*\*.

# 

# 💵 \*\*High-Salary Customers:\*\* Showed a churn rate of \*\*21.50%\*\*.

# 

# 📉 \*\*Low Credit Score Customers:\*\* Recorded a churn rate of \*\*21.48%\*\*.

# 

# 📊 \*\*Medium-Balance Customers:\*\* Showed a comparatively lower churn rate of \*\*6.67%\*\*.

# 

# These findings highlight differences in customer churn behavior across balance, salary, and credit score categories.
